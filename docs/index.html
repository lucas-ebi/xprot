About X-Prot

X-Prot picks an internal node of a phylogenetic tree and one representative sequence from each of its two child clades. It computes weighted residue conservation per clade and proposes the substitutions, insertions, and deletions that change one representative into a sequence carrying the other clade's conserved residues.

See the README for the underlying methodology and references.

Runs locally in the browser via Pyodide. No data are uploaded. The first run downloads Python packages; later runs use the browser cache.
