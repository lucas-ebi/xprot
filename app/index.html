About X-Prot

X-Prot takes a recipient representative sequence and a donor tip identifying the clade to compare it against — their most-recent-common-ancestor in the tree splits into the two subfamilies. It computes weighted residue conservation per clade and proposes the substitutions, insertions, and deletions that change the recipient into a sequence carrying the donor clade's conserved residues.

See the README for the underlying methodology and references.

Runs locally in the browser via Pyodide. No data are uploaded. The first run downloads Python packages; later runs use the browser cache.
